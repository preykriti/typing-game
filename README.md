# Type Portal

> Live demo: [https://type-portal.netlify.app/](https://type-portal.netlify.app/)

Type Portal is a browser-based typing game with an animated underwater theme. It helps you practice and measure your typing speed (WPM).

## Features

- **Normal Mode** – Type the displayed paragraph and track Time, WPM, and Accuracy.
- **Game Mode** – Words fall from the top of the screen; type a falling word and press `Enter` or `Space` to clear it. Clear words before they hit the bottom. You have 5 lives.
- **Sentence length control** – Choose Short, Medium, or Long paragraphs.
- **Live stats** – Timer, WPM, and accuracy update as you type.
- **Background sea-waves sound** with a play/pause toggle.

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Random quotes** fetched from [Quotable API](https://api.quotable.io)
